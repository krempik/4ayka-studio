# 4ayka Studio

Инди-студия разработки. Браузерные игры, E2E мессенджеры, хакерские тулзы.

## Сайт

https://krempik.github.io/4ayka-studio

## Что внутри

### Игры
- **T-Blocks** — продвинутый Tetris++ с боссами и powerups

### Инструменты
- **CryptoTool** — шифрование AES-256, RSA-OAEP, Base64, HEX, хеши
- **4AYKA OS** — поддельный хакерский рабочий стол
- **Hacker Typer** — нажимай клавиши — появляется код
- **Particle Logo** — логотип из частиц

### Мессенджер
- **H4ck Messenger** — E2E зашищённый мессенджер (отдельный репозиторий)

## Стек

HTML5 Canvas, Vanilla JS, Python, FastAPI, Web Crypto API.
