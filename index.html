Мессенджер с настоящим E2E: RSA-2048 + AES-256-GCM. Сервер не видит содержимое, приватный ключ живёт только в браузере.

О студии

Кто мы

4ayka Studio — соло-проект одного разработчика (kremp). Делаем всё сами: от прототипа до деплоя.

Во что играем

В геймдев, который можно открыть ссылкой. Никаких установщиков: Canvas, WebSocket и Web Audio решают всё.

Стек

Python + FastAPI на сервере, vanilla JS на клиенте. Фреймворки — только там, где без них нельзя.
